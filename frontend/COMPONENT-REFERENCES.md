# 21st.dev component review

Reviewed 2026-10-24. All five supplied 21st.dev pages were read, including their dependency and license listings. All five public preview images were downloaded to temporary storage and visually inspected. The component previews are not production assets. There was no connected browser for interacting with the live reference demos.

The listings identify all five as MIT-licensed. 21st.dev currently gates the complete component implementations behind an account. Public upstream implementations were also examined where accessible. No account was created, no paid component was used, no registry installer was executed, and no third-party template code was copied.

## Dependencies and assets

- **Motion** is the only new npm dependency. Its installed MIT license was inspected in `node_modules/motion/LICENSE.md`. It supplies state entrances, number interpolation, viewport reveals and countdown emphasis. No second animation package was added directly.
- **Space Grotesk** is self-hosted as an unmodified variable font, downloaded from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/spacegrotesk). The required SIL Open Font License is included at `public/fonts/OFL.txt`. No runtime third-party font request.
- **Brand assets** are byte-for-byte copies of the supplied wordmark and app icon. Their original textured backgrounds are preserved; the UI adds no gradient, glow, blur or glass effect.
- **Illustrations and pictograms** are original SVG code. The supplied gameplay screenshot is a visual reference only and is not copied into `public/` or the build.
